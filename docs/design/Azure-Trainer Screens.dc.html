EXAM NOTES
1
Every az command that creates an entity needs --resource-group; set a default with az configure --defaults group=rg-orders to stop repeating it.
2
Topics and subscriptions require Standard or Premium. Basic has queues only.
3
Max delivery count and dead-lettering on expiry are the two queue settings that route messages to the dead-letter sub-queue at orders/$DeadLetterQueue.
4
A topic has no consumers of its own; nothing is delivered until a subscription exists.
5
A new subscription gets a $Default rule that matches everything. A SQL filter only takes effect once $Default is removed.

## Review Focus

1. Expiration boundary: a key is absent at `nowMs >= expiresAtMs`; overwriting with SET without EX removes the old TTL. Task 2 test pins both.
2. Cross-filter reuse: exact keys and semantic queries include product, version and language. Task 3 checks a closer wrong-scope vector; Task 5 workload includes collisions.
3. Binary/vector integrity: FLOAT32 blobs, schema DIM, stored vectors and query vectors agree; unsupported types and dimension mismatch fail explicitly. Task 3 pins malformed queries and dimensions.
4. Invalidation coverage: both response strings and semantic hashes are removed for the affected product while another product survives. Task 2 scan/delete case and Task 6 update scenario pin this.
5. Provenance: unused Redis calls or a canned returned answer cannot prove caching; only actual operation traces, protected origin calls and the selected running image count. Task 4 SDK case and Task 5 disposable negative probe pin this.

def cached_answer(question, product, version, language, ttl):

    value = cache.get(key)

    for key in cache.scan_iter(match="ka:answer:" + product + ":*"):
        cache.delete(key)
    for key in cache.scan_iter(match="ka:sem:" + product + ":*"):
        cache.delete(key)

def remember_semantic(question, product, version, language, result, ttl):
    key = semantic_key(question, product, version, language)
    cache.hset(key, mapping={"product": product, "version": version, "language": language,
        "embedding": pack_embedding(embed(question)), "payload": encode_answer(result)})
    cache.expire(key, ttl)

def semantic_lookup(question, product, version, language, threshold):
    query = "(@product:{" + product + "} @version:{" + version + "} @language:{" + language + "})=>[KNN 1 @embedding $vec AS distance]"
    raw = cache.execute_command("FT.SEARCH", "idx:semantic", query, "PARAMS", 2,
        "vec", pack_embedding(embed(question)), "SORTBY", "distance", "ASC",
        "RETURN", 2, "payload", "distance", "DIALECT", 2)
    rows = decode_search(raw)
    for row in rows:
        if float(row["distance"]) <= threshold:
            return decode_answer(row["payload"])
    return None

def answer(question, product, version, language):
    exact = cache.get(response_key(question, product, version, language))
    if exact is not None:
        return decode_answer(exact)
    similar = semantic_lookup(question, product, version, language, 0.05)
    if similar is not None:
        return similar
    result = cached_answer(question, product, version, language, 60)
    remember_semantic(question, product, version, language, result, 60)
    return result

## Grounding and planning decisions

- Existing curriculum supplies the approved architecture and lab intent; this plan does not start a new subsystem-design approval cycle. The plan remains reviewable before execution.
- Redis-only protected answer source isolates caching learning and avoids replaying PostgreSQL/Cosmos provisioning; full live cross-service wiring belongs to Lab 13.
- Product/version/language all affect answers, so all are key/query dimensions even though the curriculum's sample key abbreviates the filters.
- Current Azure module guidance requires RediSearch with Enterprise clustering and NoEviction; missing TTL therefore teaches memory pressure/rejected writes rather than false automatic eviction. General eviction policies can be discussed in notes, but a second cache-only resource is not implemented.
- Native Redis FT commands are exposed via redis-py execute_command to avoid inventing Python-only query syntax or installing a second SDK. Binary packing and RESP2 decoding are protected, real-Python helpers; learner calls still drive storage and search.
- A Lab replay is disposable validation, not a permanent test-suite expansion; automated browser suites remain excluded.
